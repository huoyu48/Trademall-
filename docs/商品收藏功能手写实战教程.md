# OrderFlow 商品收藏功能：从需求到上线的手写实战

> 这不是一份“看完就算学会”的资料。请按顺序亲手创建文件、输入代码、编译和测试。
> 每完成一个检查点再继续，不要一次把所有代码复制进项目。

## 1. 这次要完成什么

我们给顾客商城新增一个完整的“商品收藏”模块。

完成后，顾客可以：

1. 在商品详情页收藏商品。
2. 重复点击收藏不会产生重复数据。
3. 查看当前商品是否已收藏。
4. 取消收藏。
5. 分页查看“我的收藏”。
6. 从收藏页进入商品详情或加入购物车。

### 验收规则

- 只有 `CUSTOMER` 角色能调用收藏接口。
- `customerId` 不允许由前端传入，必须从 JWT 登录上下文获取。
- 不存在或已下架的商品不能收藏。
- 同一顾客对同一商品最多只有一条收藏记录。
- 取消一个未收藏的商品不报错，直接返回“未收藏”。
- 顾客只能查询和删除自己的收藏。

亲手输入：

```sql
-- 商品收藏表：保存“哪个顾客收藏了哪个商品”。
CREATE TABLE IF NOT EXISTS product_favorite (
    id          BIGINT   NOT NULL AUTO_INCREMENT COMMENT '收藏记录主键',
    tenant_id   BIGINT   NOT NULL COMMENT '顾客账号所属租户ID',
    customer_id BIGINT   NOT NULL COMMENT '顾客ID',
    product_id  BIGINT   NOT NULL COMMENT '被收藏的商品ID',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '收藏时间',

    PRIMARY KEY (id),

    -- 唯一索引：同一顾客不能重复收藏同一商品。
    UNIQUE KEY uk_customer_product (customer_id, product_id),

    -- 支持按顾客查询，并按收藏时间倒序排列。
    KEY idx_tenant_customer_created (tenant_id, customer_id, created_at, id),
    KEY idx_product_id (product_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='顾客商品收藏';
```

### 你要能解释的点

- `PRIMARY KEY`：主键，唯一标识一条记录。
- `UNIQUE KEY`：唯一索引，除了加速查询，还会阻止重复数据写入。
- `idx_tenant_customer_created`：联合索引，对应收藏列表的查询条件和排序字段。
- 金额不在收藏表里重复保存，展示时 JOIN `product` 表获取最新价格。

### 检查点 1

1. 为什么不能只有 `product_id`？
2. 为什么要有 `(customer_id, product_id)` 唯一索引？
3. 为什么不在收藏表里保存商品名称和价格？

```java
package com.orderflow.domain.entity;

import com.baomidou.mybatisplus.annotation.FieldFill;
import com.baomidou.mybatisplus.annotation.IdType;
import com.baomidou.mybatisplus.annotation.TableField;
import com.baomidou.mybatisplus.annotation.TableId;
import com.baomidou.mybatisplus.annotation.TableName;
import lombok.Data;

import java.time.LocalDateTime;

/**
 * 收藏实体：一个 Java 对象对应 product_favorite 表中的一行。
 *
 * Entity（实体类）的作用是让 Java 字段和数据库列建立映射关系。
 * Mapper 查出一行数据后，MyBatis-Plus 会把每一列填入对应字段。
 */
@Data // Lombok 自动生成 getter、setter、toString 等方法。
@TableName("product_favorite") // 明确指定这个类对应的 MySQL 表名。
public class ProductFavorite {

    /**
     * 收藏记录主键，对应表中的 id 列。
     * IdType.AUTO 表示插入时不由 Java 生成 ID，而是使用 MySQL AUTO_INCREMENT。
     */
    @TableId(type = IdType.AUTO)
    private Long id;

    /**
     * 顾客账号所属租户，对应 tenant_id。
     * 后续查询和删除都会带上它，防止读取其他租户数据。
     */
    private Long tenantId;

    /**
     * 当前登录顾客 ID，对应 customer_id。
     * 这个值必须来自 JWT 登录上下文，不能相信前端传入的用户 ID。
     */
    private Long customerId;

    /**
     * 被收藏的商品 ID，对应 product_id。
     * 它与 product.id 建立逻辑关联，用于查询商品名称、价格和店铺。
     */
    private Long productId;

    /**
     * 顾客首次收藏的时间，对应 created_at。
     * FieldFill.INSERT 表示只在 INSERT 时填充，后续查询不会改变它。
     */
    @TableField(fill = FieldFill.INSERT)
    private LocalDateTime createdAt;
}
```

## 7. 第四步：编写 Mapper 和 SQL

```java
package com.orderflow.domain.mapper;

import com.baomidou.mybatisplus.annotation.InterceptorIgnore;
import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import com.orderflow.domain.entity.ProductFavorite;
import com.orderflow.favorite.FavoriteProductDTO;
import org.apache.ibatis.annotations.*;

import java.util.List;

/**
 * Mapper（数据访问层）只负责执行 SQL，不编写用户权限等业务判断。
 * BaseMapper<ProductFavorite> 额外提供 insert、selectById、deleteById 等基础 CRUD 方法。
 */
@Mapper // 告诉 Spring/MyBatis：请为这个接口生成可注入的代理对象。
public interface ProductFavoriteMapper extends BaseMapper<ProductFavorite> {

    /**
     * 顾客能浏览不同商家的商品，因此这里跳过默认租户条件。
     * SQL 仍然使用 productId 和 status 明确限制了查询范围。
     */
    @InterceptorIgnore(tenantLine = "true")
    @Select("SELECT COUNT(*) FROM product WHERE id = #{productId} AND status = 1")
    // @Param 把 Java 参数命名为 productId，SQL 通过 #{productId} 安全绑定。
    long countActiveProduct(@Param("productId") Long productId);

    /**
     * 利用唯一索引和 ON DUPLICATE KEY UPDATE 实现幂等插入。
     * 幂等：同一请求执行一次或多次，最终状态相同。
     */
    @Insert("""
        INSERT INTO product_favorite (tenant_id, customer_id, product_id, created_at)
        VALUES (#{favorite.tenantId}, #{favorite.customerId},
                #{favorite.productId}, #{favorite.createdAt})
        ON DUPLICATE KEY UPDATE id = id
        """)
    // 返回值是 SQL 影响行数；该业务只关心最终已收藏状态。
    int insertIdempotently(@Param("favorite") ProductFavorite favorite);

    /**
     * 使用租户+顾客+商品三个条件删除，防止越权。
     * 返回 1 表示真正删除了数据，返回 0 表示本来就没有收藏。
     */
    @InterceptorIgnore(tenantLine = "true")
    @Delete("""
        DELETE FROM product_favorite
        WHERE tenant_id = #{tenantId}
          AND customer_id = #{customerId}
          AND product_id = #{productId}
        """)
    int deleteByCustomerAndProduct(@Param("tenantId") Long tenantId,
                                   @Param("customerId") Long customerId,
                                   @Param("productId") Long productId);

    /**
     * 查询当前顾客对某商品是否存在收藏记录。
     * 由于数据库有唯一索引，返回值只会是 0 或 1。
     */
    @InterceptorIgnore(tenantLine = "true")
    @Select("""
        SELECT COUNT(*)
        FROM product_favorite
        WHERE tenant_id = #{tenantId}
          AND customer_id = #{customerId}
          AND product_id = #{productId}
        """)
    long countByCustomerAndProduct(@Param("tenantId") Long tenantId,
                                   @Param("customerId") Long customerId,
                                   @Param("productId") Long productId);

    /**
     * 计算当前顾客的有效收藏总数，用于前端分页组件。
     * INNER JOIN 中的 p.status = 1 会过滤已下架或已不存在的商品。
     */
    @InterceptorIgnore(tenantLine = "true")
    @Select("""
        SELECT COUNT(*)
        FROM product_favorite f
        INNER JOIN product p ON p.id = f.product_id AND p.status = 1
        WHERE f.tenant_id = #{tenantId}
          AND f.customer_id = #{customerId}
        """)
    long countFavoriteProducts(@Param("tenantId") Long tenantId,
                               @Param("customerId") Long customerId);

    /**
     * 通过 JOIN 一次查出收藏、商品、分类和店铺字段。
     * 这样避免每查到一条收藏就额外查一次商品的 N+1 问题。
     */
    @InterceptorIgnore(tenantLine = "true")
    @Select("""
        -- AS 别名会被 MyBatis 根据驼峰规则映射到 FavoriteProductDTO。
        SELECT f.id AS favorite_id,
               f.product_id,
               p.product_code,
               p.product_name,
               p.unit_price_cent,
               p.category_id,
               c.category_name,
               p.store_id,
               s.store_name,
               COALESCE(p.sales, 0) AS sales,
               f.created_at AS favorited_at
        FROM product_favorite f
        INNER JOIN product p ON p.id = f.product_id AND p.status = 1
        LEFT JOIN category c ON c.id = p.category_id
        LEFT JOIN store s ON s.id = p.store_id
        WHERE f.tenant_id = #{tenantId}
          AND f.customer_id = #{customerId}
        -- 先按收藏时间倒序；id 用于保证同一秒的排序仍然稳定。
        ORDER BY f.created_at DESC, f.id DESC
        -- offset 表示跳过多少条，size 表示最多返回多少条。
        LIMIT #{offset}, #{size}
        """)
    List<FavoriteProductDTO> selectFavoriteProducts(@Param("tenantId") Long tenantId,
                                                    @Param("customerId") Long customerId,
                                                    @Param("offset") long offset,
                                                    @Param("size") long size);
}
```

## 9. 第六步：编写 Service 业务逻辑

新建：

```text
src/main/java/com/orderflow/favorite/FavoriteServiceImpl.java
```

```java
package com.orderflow.favorite;

import com.orderflow.common.BizErrorCode;
import com.orderflow.common.BizException;
import com.orderflow.common.PageResult;
import com.orderflow.domain.entity.ProductFavorite;
import com.orderflow.domain.mapper.ProductFavoriteMapper;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.util.List;

/**
 * 收藏业务实现类。
 *
 * Service 层是业务功能的核心：
 * 1. 先校验业务条件；
 * 2. 组装 Entity；
 * 3. 调用 Mapper 读写数据库；
 * 4. 组装接口返回值。
 */
@Service // 将本类注册到 Spring IoC 容器，供 Controller 注入。
public class FavoriteServiceImpl implements FavoriteService {

    /** 限制单次查询的最大数量，防止大查询拖垮数据库。 */
    private static final int MAX_PAGE_SIZE = 100;

    /** final 表示依赖在构造完成后不能被替换。 */
    private final ProductFavoriteMapper favoriteMapper;

    /** 构造器注入：Spring 把 Mapper 对象传入 Service。 */
    public FavoriteServiceImpl(ProductFavoriteMapper favoriteMapper) {
        this.favoriteMapper = favoriteMapper;
    }

    /** 收藏商品。 */
    @Override // 表示这个方法实现了 FavoriteService.add。
    @Transactional // 在事务内执行；出现运行时异常会回滚。
    public FavoriteStatusDTO add(Long tenantId, Long customerId, Long productId) {
        // 业务校验：只允许收藏存在且已上架的商品。
        if (favoriteMapper.countActiveProduct(productId) == 0) {
            // BizException 会被全局异常处理器转换为统一 JSON 错误响应。
            throw new BizException(BizErrorCode.PRODUCT_NOT_FOUND);
        }

        // 组装待写入数据库的 Entity。
        ProductFavorite favorite = new ProductFavorite();
        favorite.setTenantId(tenantId);
        favorite.setCustomerId(customerId);
        favorite.setProductId(productId);
        favorite.setCreatedAt(LocalDateTime.now());

        // 这个 Mapper 方法能够安全处理重复收藏请求。
        favoriteMapper.insertIdempotently(favorite);

        // 不直接返回 Entity，而是只返回前端需要的状态 DTO。
        return new FavoriteStatusDTO(productId, true);
    }

    /** 取消收藏。 */
    @Override
    @Transactional
    public FavoriteStatusDTO remove(Long tenantId, Long customerId, Long productId) {
        // 删除条件包含租户和顾客，不能只根据 productId 删除。
        favoriteMapper.deleteByCustomerAndProduct(tenantId, customerId, productId);
        return new FavoriteStatusDTO(productId, false);
    }

    /** 查询收藏状态。 */
    @Override
    @Transactional(readOnly = true) // 只读事务，用来表明此方法不修改数据。
    public FavoriteStatusDTO status(Long tenantId, Long customerId, Long productId) {
        boolean favorited = favoriteMapper
                .countByCustomerAndProduct(tenantId, customerId, productId) > 0;
        return new FavoriteStatusDTO(productId, favorited);
    }

    /** 分页查询“我的收藏”。 */
    @Override
    @Transactional(readOnly = true)
    public PageResult<FavoriteProductDTO> page(
            Long tenantId, Long customerId, int page, int size) {

        // 参数安全处理：页码不小于 1，每页不超过 100。
        int safePage = Math.max(page, 1);
        int safeSize = Math.min(Math.max(size, 1), MAX_PAGE_SIZE);

        // SQL LIMIT 使用的是 offset，不是页码。
        // 第 1 页 offset=0，第 2 页 offset=size。
        long offset = (long) (safePage - 1) * safeSize;

        // 先查总数，前端分页组件需要它来计算总页数。
        long total = favoriteMapper.countFavoriteProducts(tenantId, customerId);

        // 没有数据时不再执行列表 SQL。
        List<FavoriteProductDTO> list = total == 0
                ? List.of()
                : favoriteMapper.selectFavoriteProducts(
                        tenantId, customerId, offset, safeSize);

        // 使用项目统一分页结构：list + total + page + size。
        return PageResult.of(list, total, safePage, safeSize);
    }
}
```

```java
import org.springframework.security.access.prepost.PreAuthorize;
import org.springframework.web.bind.annotation.*;

/**
 * 顾客商品收藏 HTTP 接口。
 *
 * Controller 是请求入口：解析 URL 参数、取得登录人身份、
 * 调用 Service，再把 Service 结果封装成统一 JSON。
 */
@RestController // @Controller + @ResponseBody，方法返回值会自动转成 JSON。
@RequestMapping("/customer/favorites") // 当前类中所有 URL 的统一前缀。
@PreAuthorize("hasRole('CUSTOMER')") // 在进入方法前校验 JWT 中是否有 CUSTOMER 角色。
public class FavoriteController {

    /** Controller 依赖 Service，不直接访问数据库。 */

    /** 构造器注入：Spring 创建 Controller 时传入 FavoriteServiceImpl。 */
    public FavoriteController(FavoriteService favoriteService) {
        this.favoriteService = favoriteService;
    }

    /**
     * 收藏商品。
     * 例如 POST /api/customer/favorites/15，productId 就是 15。
     */
    @PostMapping("/{productId}") // 将 HTTP POST 请求映射到此方法。
    public ApiResponse<FavoriteStatusDTO> add(@PathVariable Long productId) {
        // @PathVariable 把 URL 中的 {productId} 转换为 Long 参数。
        LoginUser customer = currentCustomer();

        // tenantId/customerId 来自登录身份，只有 productId 来自 URL。
        return ApiResponse.success(favoriteService.add(
                customer.getTenantId(), customer.getUserId(), productId));
    }

    /** DELETE 表示删除收藏关系，不会删除商品本身。 */
    @DeleteMapping("/{productId}")
    public ApiResponse<FavoriteStatusDTO> remove(@PathVariable Long productId) {
        LoginUser customer = currentCustomer();
        return ApiResponse.success(favoriteService.remove(
                customer.getTenantId(), customer.getUserId(), productId));
    }

    /** GET 只读取数据，用来初始化详情页收藏按钮。 */
    @GetMapping("/{productId}/status")
    public ApiResponse<FavoriteStatusDTO> status(@PathVariable Long productId) {
        LoginUser customer = currentCustomer();
        return ApiResponse.success(favoriteService.status(
                customer.getTenantId(), customer.getUserId(), productId));
    }

    /**
     * 分页查询当前顾客的收藏。
     * 例如 GET /api/customer/favorites?page=1&size=12。
     */
    @GetMapping
    public ApiResponse<PageResult<FavoriteProductDTO>> page(
            @RequestParam(defaultValue = "1") int page, // 前端不传时默认第 1 页。
            @RequestParam(defaultValue = "12") int size) { // 前端不传时默认每页 12 条。

        LoginUser customer = currentCustomer();
        return ApiResponse.success(favoriteService.page(
                customer.getTenantId(), customer.getUserId(), page, size));
    }

    /**
     * 从 Spring SecurityContext 获取 JWT 解析后的当前顾客。
     * customerId 不从请求参数获取，否则用户可以伪造别人的 ID。
     */
    private LoginUser currentCustomer() {
        // JwtAuthFilter 已经把解析后的 LoginUser 放入 SecurityContext。
        LoginUser customer = SecurityUtils.current();
        if (customer == null) {
            throw new BizException(40102, "请先登录");
        }
        return customer;
    }
```

```ts
// 引入顾客端专用 Axios 实例。
// customerHttp 会自动在请求头中添加顾客 JWT，并统一处理错误响应。
import http from './customerHttp'

// import type 只导入 TypeScript 类型，打包后不会生成额外 JavaScript。
import type { PageResult, Product } from '../types'

/** 后端返回的收藏状态。 */
export interface FavoriteStatus {
  // 本次操作对应的商品 ID。
  productId: number

  // true=已收藏，false=未收藏。
  favorited: boolean
}

/**
 * 收藏列表中的商品数据。
 * Pick<Product, ...> 从公共 Product 接口复用指定字段，
 * 避免在这里重复声明商品名称、价格和店铺等类型。
 */
export interface FavoriteProduct extends Pick<Product,
  'productCode' | 'productName' | 'unitPriceCent' |
  'categoryId' | 'categoryName' | 'storeId' | 'storeName' | 'sales'> {
  favoriteId: number // 收藏记录 ID，作为 v-for 的唯一 key。
  productId: number // 商品 ID，用于跳转详情和取消收藏。
  favoritedAt: string // 后端 LocalDateTime 序列化后的时间字符串。
}

/**
 * 收藏商品。
 * <FavoriteStatus> 是泛型，告诉 TypeScript 这个 Promise 成功后返回什么结构。
 */
export function addFavorite(productId: number) {
  // 反引号模板字符串会把 productId 拼入 URL。
  return http.post<FavoriteStatus>(`/customer/favorites/${productId}`)
}

/** DELETE 只删除顾客和商品之间的收藏关系。 */
export function removeFavorite(productId: number) {
  return http.delete<FavoriteStatus>(`/customer/favorites/${productId}`)
}

/** 进入详情页时调用，用于决定按钮显示“收藏”还是“已收藏”。 */
export function favoriteStatus(productId: number) {
  return http.get<FavoriteStatus>(
    `/customer/favorites/${productId}/status`
  )
}

/**
 * 分页查询当前顾客的收藏列表。
 * page/size 有默认值，调用 favoriteProducts() 时就是第 1 页、每页 12 条。
 */
export function favoriteProducts(page = 1, size = 12) {
  // params 会被 Axios 转成 ?page=1&size=12 查询字符串。
  return http.get<PageResult<FavoriteProduct>>('/customer/favorites', {
    params: { page, size }
  })
}
```

```ts
/**
 * 根据当前状态决定调用收藏还是取消收藏接口。
 * 只有后端成功后才更新前端状态，避免界面和数据库不一致。
 */
async function toggleFavorite() {
  // p 保存当前商品详情；数据还未加载完时不执行操作。
  if (!p.value) return

  // 请求开始前进入 loading 状态。
  favoriteLoading.value = true
  try {
    // 三元表达式：已收藏就调用删除，未收藏就调用新增。
    const result = favorited.value
      ? await removeFavorite(p.value.id)
      : await addFavorite(p.value.id)

    // 以后端返回值为准，不在前端自己猜测最终状态。
    favorited.value = result.favorited

    // 根据最新状态给用户反馈。
    ElMessage.success(
      result.favorited ? '收藏成功' : '已取消收藏'
    )
  } finally {
    // finally 无论成功还是失败都会执行，避免按钮一直处于 loading。
    favoriteLoading.value = false
  }
}
```

```vue
function addToCart(item: FavoriteProduct) {

  const product: Product = {
    // 收藏 DTO 使用 productId，通用 Product 使用 id。
    id: item.productId,
    productCode: item.productCode,
    productName: item.productName,
    unitPriceCent: item.unitPriceCent,
    // 收藏 SQL 已经过滤 p.status=1，因此这里可以填入上架状态。
    status: 1,
    categoryId: item.categoryId,
    categoryName: item.categoryName,
    storeId: item.storeId,
    storeName: item.storeName,
    sales: item.sales
  }

  // 第二个参数 1 表示本次加入 1 件。
  cart.add(product, 1)
  ElMessage.success('已加入购物车')
}

async function cancelFavorite(item: FavoriteProduct) {
  // 记录当前正在删除哪一条，避免所有卡片同时显示 loading。
  removingId.value = item.productId

  try {
    // 调用 DELETE 接口，后端会根据 JWT 限制只删除当前顾客的记录。
    await removeFavorite(item.productId)
    ElMessage.success('已取消收藏')

    // 删除当前页最后一条时，回到上一页。
    if (list.value.length === 1 && page.value > 1) {
      page.value -= 1
    }

    // 重新从服务器加载，确保前端列表和 MySQL 数据一致。
    await load()
  } finally {
    removingId.value = null
  }
}

  page.value = nextPage

  load()
}
```

## 18. 常见错误与排查方法

### 18.1 `cannot find symbol`

先检查：

- 类名大小写是否一致。
- package 路径是否和文件夹一致。
- import 是否导入了正确类。
- 方法名是 `countActiveProduct` 还是其他拼写。

### 18.2 `Table 'product_favorite' doesn't exist`

检查：

- 后端是否重启。
- Flyway 启动日志中是否执行了 V12。
- 迁移文件是否放在 `src/main/resources/db/migration` 中。

### 18.3 接口返回 403

检查：

- 请求是否带上 `Authorization: Bearer token`。
- token 是否来自顾客登录，而不是商家登录。
- JWT 中是否包含 `CUSTOMER` 角色。

### 18.4 重复收藏出现两条数据

检查：

- 数据库是否真正创建了 `uk_customer_product` 唯一索引。
- Mapper 的 INSERT 是否使用了 `ON DUPLICATE KEY UPDATE`。

### 18.5 收藏列表能看到别人的数据

检查所有查询和删除 SQL 是否都同时包含：

```sql
tenant_id = ? AND customer_id = ?
```

## 19. 正确的手写训练方法

不要把文档和 VS Code 并排后逐字复制。每层都按以下方式练习：

1. 先只看这一层的需求，关掉源码。
2. 自己写出类名、字段和方法签名。
3. 再打开参考源码，只校对结构。
4. 关掉参考源码，补完方法内部逻辑。
5. 运行编译，根据第一个错误修改，不要一次处理所有错误。
6. 编译通过后，对着自己的代码口头讲一遍调用链。

### 你要能脱离文档写出的核心部分

```text
1. 数据库表的主键、唯一索引和查询索引
2. Entity 的字段映射
3. Mapper 的查询、插入和删除 SQL
4. Service 中的业务校验、组装实体和分页计算
5. Controller 中的 URL、HTTP 方法、身份获取和 Service 调用
6. Vue 中的 API 调用、响应式状态和用户交互
```
