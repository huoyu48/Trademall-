## 2026-08-18：顾客—商家实时咨询

本次验证同样在本地 Docker Compose 环境完成；聊天消息以 MySQL 为事实来源，WebSocket 仅用于事务提交后的实时推送。

| 项目 | 场景 | 结果 |
| --- | --- | --- |
| 后端测试 | `./mvnw -q test` | 7/7 通过 |
| 前端检查与构建 | `npm run type-check && npm run build` | 通过 |
| 会话权限 | 顾客按商品建立会话，错误租户商家读取该会话 | 被拒绝；对应租户商家可读取 |
| 消息持久化与未读数 | 顾客发送、对应商家回复、顾客补拉历史 | 双方消息均落库；未读数正确变化 |
| WebSocket 推送 | 顾客与对应商家各连接一个 STOMP 客户端 | 两端收到同一条已持久化消息 ID |

该验证说明本地单实例环境下的功能正确性；多后端实例部署时，需将 Spring Simple Broker 替换为外部 STOMP Broker 或增加跨实例广播。
